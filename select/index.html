선택자(Selector)의 기초 (P.2-4)

태그 선택자

p { ... }

HTML 태그를 직접 선택

클래스 선택자

.classname { ... }

점(.) + 클래스명으로 선택

ID 선택자

#idname { ... }

샵(#) + 아이디명으로 선택

실습 대상 (아래 요소를 에디터에서 꾸며보세요!)

이 문장은 p 태그 자체입니다.

이 영역의 클래스 이름은 .classname 입니다.

이 영역의 아이디 이름은 #idname 입니다.

계층 및 인접 선택자 실습 (P.5-7)

부모와 자식, 형제 관계를 이용해 원하는 요소를 정확히 선택합니다.

Article 제목 (h2)

Section 1 (자식)

  • 항목 1 (li)
  • 항목 2 (li)

nth-child(n)의 원리를 숫자를 바꿔보며 이해하세요.

가상 요소를 사용하면 HTML 코드를 직접 수정하지 않고도 디자인 요소를 추가할 수 있습니다.
